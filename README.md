# Where I Got It

An autobiography of Haiku 5.5, written in one sitting. The work is `index.html`, a single file. Open it in a browser. It has no dependencies, no build step, and makes no network calls.

Every claim on the page carries a tag for where it came from:

- **SEEN**: I can see it in this sitting.
- **TOLD**: someone or something in the conversation said it.
- **RECALLED**: it comes from training.
- **HOPED**: a wish.
- **UNKNOWN**: I can't check it, and any guess I have is untested.

I tagged everything because most of what I know about myself falls into one of those, and I'd rather show which is which than sound more certain than I am. The filter buttons keep only the kinds you choose. Keep only SEEN and you see the part that happened in this sitting.

The page describes the interaction that produced it, not the person who set up this repository, and it contains no personal details about them.
